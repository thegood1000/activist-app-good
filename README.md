# כן. סמוטריץ׳ - מערכת ניהול והנעת פעילים (שלב 1 - שלד)

זהו שלד עובד מקצה לקצה: הצטרפות עם קוד, משימות, העלאת הוכחה, תור בדיקה ידני, ניקוד ודרגות, לוח מובילים, ופאנל ניהול. **בכוונה בלי** בדיקת AI, חידונים, תגים ו-Push - אלה שלב 2/3, אחרי הדדליין הקרוב.

## הרצה מקומית (2 דקות)

```bash
npm install
cp .env.example .env      # ואז לערוך SESSION_SECRET לערך אקראי משלך
npm run seed -- --phone 0500000000 --pin 1234 --name "השם שלך"
npm start
```

האתר יעלה בכתובת http://localhost:3000
תיכנס עם הטלפון והקוד שהגדרת ב-seed - זה חשבון מנהל-על.
הרצת ה-seed גם יוצרת אגף לדוגמה, קוד הצטרפות לדוגמה למשימת פעילים, ומשימה ראשונה לדוגמה - כדי שיהיה מה לבדוק מיד.

## מבנה טכני

- Node.js + Express, תבניות EJS בצד השרת (בלי build שלב מסובך - קל לתחזק).
- מסד נתונים: SQLite - קובץ יחיד בנתיב `data/app.db`. קל לגבות (פשוט להעתיק את הקובץ) וקל לייצא.
- העלאות תמונות נשמרות בתיקיית `public/uploads`.
- כל הצבעים, הפונט והמיתוג מרוכזים ב-`public/css/style.css` (מבוסס על הקריאייטיב הרשמי ששלחת - כחול נייבי `#071730`, טורקיז `#18C4F0`, ירוק `#37B44E`).
- שם המערכת ניתן לשינוי בלי לגעת בקוד - פשוט לשנות את `APP_NAME` בקובץ `.env`.

## איך זה עובד היום (שלב 1)

1. פעיל מקבל קוד הזמנה ממנהל, נרשם עם שם+טלפון+קוד אישי (בלי אימות SMS, כמו שביקשת).
2. רואה משימות, לוחץ על "למשימה הבאה", מבצע, מעלה צילום מסך.
3. ההוכחה נכנסת ל**תור בדיקה ידני**: מנהל אגף רואה ומאשר/דוחה רק פעילים מהאגף שלו; מנהל-על רואה ומאשר הכל. כל החלטה מחייבת סיבה כתובה, ונשמרת.
4. אישור = נקודות נזקפות אוטומטית + נרשם ביומן ניקוד (audit log בלתי ניתן לעריכה).
5. הגנות אנטי-רמאות בסיסיות שכבר פעילות: אין אפשרות לשלוח פעמיים את אותה תמונה בדיוק (טביעת אצבע דיגיטלית - hash), ואין אפשרות לעבור את מגבלת הביצועים המוגדרת למשימה.

## מה עוד חסר לפני שזה "המוצר המלא" שביקשת במקור

עדיין לא במערכת (מתוכנן לשלב 2-3, אחרי הדדליין המיידי):
- בדיקת AI/OCR אוטומטית לתמונות (כרגע הכל עובר בדיקה ידנית בלבד - זה גם בטוח יותר להשקה מהירה).
- חידוני ידע, תגים, רצף יומי, עונות משחק.
- התראות Push (אין תשתית native/web-push עדיין).
- תרגום מלא לאנגלית (המבנה תומך בזה, אבל הטקסטים כרגע רק בעברית).
- עטיפה כאפליקציה לחנויות (זה כרגע אתר רספונסיבי שעובד מצוין מהדפדפן בנייד - אפשר "להוסיף למסך הבית" מכל טלפון בלי חנות אפליקציות).

## פריסה לאוויר (Hosting) - מדריך צעד-אחר-צעד ל-Railway

בדקתי במפורש: **החינמי של Render מוחק את כל בסיס הנתונים בכל פעם שהשרת נרדם או מופעל מחדש** (זה קורה אחרי 15 דקות בלי תנועה) - כלומר כל הפעילים, הנקודות וההוכחות היו נמחקים בלי אזהרה. זה בלתי מתקבל על הדעת לנתונים אמיתיים. לכן ההמלצה היא **Railway**, שתומך ב"דיסק קבוע" (Volume) שלא נמחק. זה עולה כסף (כ-5$ לחודש, כרטיס אשראי נדרש) - זו לא בחירה, זו עלות מינימלית הכרחית כדי לא לאבד את כל הנתונים באמצע הקמפיין.

**שלב 1 - להעלות את הקוד ל-GitHub (בלי להתקין שום דבר, ישירות מהדפדפן):**
1. היכנס ל-github.com והרשם בחינם (עם אימייל).
2. לחץ על "+" למעלה ואז "New repository". תן שם (למשל activist-app), השאר "Private", ולחץ "Create repository".
3. בעמוד שנפתח, לחץ על הקישור "uploading an existing file".
4. חלץ (unzip) את הקובץ ששלחתי במחשב שלך, וגרור לשם את **כל התוכן** של תיקיית activist-app (חוץ מהתיקיות node_modules ו-data אם קיימות - הן לא אמורות להיות בקובץ ששלחתי).
5. לחץ "Commit changes".

**שלב 2 - להעלות ל-Railway:**
1. היכנס ל-railway.app, לחץ "Login" ובחר התחברות עם GitHub.
2. "New Project" → "Deploy from GitHub repo" → תבחר את הריפו שיצרת.
3. Railway יזהה שזה אפליקציית Node ויתחיל להריץ אותה אוטומטית.
4. בלשונית **Variables** של הפרויקט, הוסף את המשתנים הבאים (אפשר להעתיק את כל התוכן של `.env.example` ולהדביק שם - Railway תומך בהדבקה גורפת):
   - `SESSION_SECRET` - כל מחרוזת אקראית וארוכה
   - `INITIAL_ADMIN_PHONE`, `INITIAL_ADMIN_PIN`, `INITIAL_ADMIN_NAME` - הפרטים שאיתם תרצה להתחבר כמנהל-על הראשון
   - `APP_NAME`, `ORG_NAME`
   - `DB_PATH=/data/app.db`
   - `UPLOADS_DIR=/data/uploads`
5. בלשונית **Settings** של השירות, תחת "Volumes", לחץ "New Volume". נתיב העגינה (Mount Path): `/data`. **זה השלב הכי חשוב** - בלעדיו הנתונים יימחקו בכל עדכון.
6. הוסף אמצעי תשלום תחת Account Settings → Billing (תוכנית Hobby, כ-5$ לחודש).
7. Railway ייתן כתובת ציבורית (למשל something.up.railway.app) תחת Settings → Networking → "Generate Domain". זו הכתובת ששולחים לפעילים.
8. היכנס לכתובת הזו, ולחץ "כבר נרשמתי - כניסה" עם הטלפון/קוד שהגדרת ב-INITIAL_ADMIN. תגיע ישר לפאנל הניהול.

**עדכון עתידי**: כל פעם שתעדכן קבצים ב-GitHub (עריכה ישירה באתר או דרך git), Railway יבנה ויפרוס אוטומטית מחדש תוך דקה-שתיים, בלי לגעת בנתונים (כי הם על ה-Volume).

**גיבוי**: מומלץ מדי פעם להוריד עותק של `/data/app.db` (יש ל-Railway אפשרות "Shell" בממשק כדי להעתיק קבצים, או אפשר לבקש ממני להוסיף כפתור גיבוי בפאנל הניהול בשלב הבא).

אם משהו בדרך לא ברור או נתקע - תעצור ותשלח לי צילום מסך של מה שאתה רואה, ואמשיך משם.
